## Executive Summary

**Assessment — HIGH confidence:** A sustained, multi-host intrusion affected all nine covered systems between `2024-05-24T17:49:46Z` and `2026-06-21T13:35:13`. **Assessment — HIGH confidence:** The adversary sought enterprise identity control. Password dumping, Mimikatz, Inveigh, Kerberoasting-related code, Rubeus, BloodHound/SharpHound, and a certificate-backed request for a Kerberos ticket collectively show an effort to discover privilege paths and acquire reusable authentication material.

**Permitted but not proven — MODERATE confidence:**

If no action is taken, **assessment — HIGH confidence**, the organisation risks repeated credential theft and workstation reinfection; **MODERATE confidence**, it risks domain takeover, malicious software distribution, and authentication persistence through certificates; and **LOW confidence**, it risks data theft because no specific collection, archive transfer, or confirmed exfiltration is included.
