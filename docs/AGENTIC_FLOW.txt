================================================================================
                      STEP 1: COLLECT ARTIFACTS
================================================================================

    Blueprint contains list of artifacts to collect:

    Example: [Agentic] Purple Team (11 artifacts)
    +----------------------------------------------------------+
    |  - Windows.Hayabusa.Rules                                |
    |  - Windows.Detection.Malfind                             |
    |  - DetectRaptor.Windows.Detection.Powershell.PSReadline  |
    |  - Windows.System.TaskScheduler                          |
    |  - Generic.System.Pstree                                 |
    |  - ... (6 more)                                          |
    +----------------------------------------------------------+
                              |
                              v

    Velociraptor runs ALL artifacts on each client simultaneously

         Client 1                    Client 2                    Client N
    +----------------+          +----------------+          +----------------+
    | Artifact 1     |          | Artifact 1     |          | Artifact 1     |
    | Artifact 2     |          | Artifact 2     |          | Artifact 2     |
    | Artifact 3     |          | Artifact 3     |          | Artifact 3     |
    | ...            |          | ...            |          | ...            |
    +----------------+          +----------------+          +----------------+
           |                           |                           |
           +---------------------------+---------------------------+
                                       |
                                       v
                            [Wait for completion]
                            (poll every 30 seconds)
