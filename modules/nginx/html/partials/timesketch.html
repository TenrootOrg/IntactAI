Collect forensic artifacts and create investigation timelines

TimeSketch is installed but stopped

The TimeSketch container is not running, so sketch creation and timeline ingest will fail. Start it with docker start intact_timesketch_web.

Velociraptor is installed but stopped

KAPE collection dispatches the Windows.KapeFiles.Targets Velociraptor artifact, so this page can't collect anything until the Velociraptor server is running. Start it with docker start intact_velociraptor.

Velociraptor is not installed

KAPE collection dispatches the Windows.KapeFiles.Targets Velociraptor artifact — this workflow cannot run on a host without Velociraptor. Install it via Settings → Online Upgrade (or enable modules.velociraptor.enabled: true in config.yaml and re-run install.sh).
