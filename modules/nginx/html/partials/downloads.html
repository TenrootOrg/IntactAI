Other Downloads

Use one of these when the modern build won't run — old OS or unusual libc. Buttons grey out when the bundled binary isn't present (re-run install.sh to fetch).

Windows Legacy

EXE for Server 2008 R2 / Win 7

Pinned older Velociraptor release that still supports the TLS / Win32 API surface available on Win 7 / Server 2008 R2 / 2012. The modern EXE loads but crashes on first phone-home on these hosts.

Download Legacy EXE

Linux Legacy

For old-glibc distros

For hosts whose glibc is older than 2.28 — CentOS 7, RHEL 7, Ubuntu 16.04, Debian 9. The modern binary throws GLIBC_2.28 not found on load there.

Download Legacy Linux

Linux (musl)

Statically linked, no libc deps

Statically linked against musl libc — zero glibc dependency, runs on any Linux x86_64 including Alpine containers, Sophos UTM, BusyBox appliances and other minimal environments where neither the modern nor the legacy glibc build can load.

Download Linux (musl)

Installation

Windows

Install (MSI, recommended)

msiexec /i velociraptor_client.msi /qn

Uninstall

msiexec /x velociraptor_client.msi /qn

Linux

Foreground test

chmod +x velociraptor && sudo ./velociraptor client -v

Permanent install (systemd)

install + write unit + enable --now

Uninstall

disable + remove unit + remove binary
