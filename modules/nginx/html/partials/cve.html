CVE Scan

Velociraptor is installed but stopped

The "Run from Velociraptor" path dispatches a hunt for the 4 inventory artifacts (installed-software / startup / scheduled-tasks / services). Without a running Velociraptor server, only the manual CSV-upload path works. Start it with docker start intact_velociraptor.

Velociraptor is not installed

The "Run from Velociraptor" and "From existing flow" paths dispatch the inventory artifacts (Windows.Sys.Programs + 3 others) — these need a running Velociraptor server. The manual CSV-upload path still works without Velociraptor. To enable hunt dispatch, install Velociraptor via Settings → Online Upgrade.

Match each host's installed software against NVD and get a CSV of vulnerable products ranked by CVSS — a patch list for IT.

Dispatch a new hunt + auto-scan Recommended

Dispatch the cve_management hunt across all online clients, poll until it finishes, then automatically pull CSVs and run the NVD scan. One cve_scan workflow row tracks the full flow end-to-end and the CVE CSV download appears when done.

minutes (1 – 720)

Or upload a Velociraptor hunt ZIP

In Velociraptor, open the hunt and use Download Results → Full Download (or Summary (CSV Only)) to get the artifact bundle. Drop that ZIP here — we'll unpack it, merge each artifact's per-client CSVs, and run the NVD scan. The run is auto-named with the current timestamp.

Or scan an existing Velociraptor flow / hunt

The flow / hunt must have collected Windows.Sys.Programs, DetectRaptor.Windows.Detection.Applications, DetectRaptor.Windows.Detection.LolRMM, and Generic.Client.Info. Missing artifacts are skipped.
