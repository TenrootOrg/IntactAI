Memory Forensics

VolWeb is installed but stopped

The VolWeb backend container isn't running — Volatility 3 plugin execution and YARA scanning will fail. Start it with docker start intact_volweb_backend.

Velociraptor is installed but stopped

Endpoint memory acquisition dispatches the Windows.Memory.Acquisition Velociraptor artifact. Without a running Velociraptor server, you can still analyse an operator-supplied dump via the upload path. Start it with docker start intact_velociraptor.

Velociraptor is not installed

Endpoint memory acquisition uses the Windows.Memory.Acquisition Velociraptor artifact — that path is unavailable on this host. The upload path (operator-supplied memory dump) still works. To enable acquisition, install Velociraptor via Settings → Online Upgrade.

Capture Windows physical memory via Velociraptor, run Volatility 3 plugins + YARA scanning in VolWeb, and extract findings. The findings feed the case for analysis.
