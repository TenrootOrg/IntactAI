LINUX LEGACY

For old-glibc distros

For hosts whose glibc is older than 2.28 — CentOS 7, RHEL 7, Ubuntu 16.04, Debian 9. The modern binary throws GLIBC_2.28 not found on load there. Same pinned older release as the Windows Legacy build.

LINUX (musl)

Statically linked, no libc deps

Statically linked against musl libc — zero glibc dependency, runs on any Linux x86_64 including Alpine containers, Sophos UTM, BusyBox embedded appliances, and other minimal environments where neither the modern nor the legacy glibc build can load.

Installation Instructions

Windows

# Run MSI as Administrator
msiexec /i velociraptor.msi

Linux

# Run as root
chmod +x velociraptor
sudo ./velociraptor service install
sudo ./velociraptor service start
